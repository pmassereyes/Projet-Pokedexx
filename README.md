# Projet-Pokedexx
 
Petit Pokédex réalisé en 2025 pour apprendre **Vue.js** (front) et **Node.js** (back).
 
- **Front** : site Vue.js
- **nodePokemonApi** : API Node.js qui fournit les données au site
## Lancer le projet
 
```bash
# API
cd nodePokemonApi
npm install
npm start
 
# Front (dans un autre terminal)
npm install
npm run dev
```
 
## Notions pratiquées
 
- **Vue.js** : composants, props, réactivité, directives, routing, appels API
- **Node.js** : création d'une API REST, routes, gestion des requêtes
